# ✦ blessy!! — Python Developer Portfolio

> _"All the code in the world, with zero compromises."_ ⚡  

A modern, high-performance developer portfolio showcasing backend systems, asynchronous bots, and clean software architecture.

---

## 🩵 Visual & Design Highlights

- **Modern Design System:** Clean, crisp light palette (`#f3f4f6`, `#010521`, `#97e6ff`, `#0055ff`), high-contrast typography with Geist & Geist Mono.
- **Fluid Interactive Background:** Dynamic WebGL gradient mesh shader that smoothly responds to mouse movement and ambient motion.
- **Floating Glass Navbar:** Blurred elevation header with pill navigation and live status indicator.
- **Signature Split & Outline Actions:** Dual-action `.ha-split` cyan button with platform caret dropdown and `.ha-outline` social buttons.
- **Hero App Architecture Mockup:** Precision window mockup featuring live module status and Python backend runtime preview.
- **High-Tech Bento Grid:** Structured cards highlighting core Python stack, live bots, APIs, and creative inspirations.
- **Full Interactive Audio Player:** 18-track music player with album covers, scrubbable progress bar, volume controls, and live now-playing disc animation.
- **Interactive Gallery & Lightbox:** Category filtering (Rimuru, Anime, Life, Series) with fullscreen keyboard-accessible lightbox and swipe gestures.
- **Common Questions (FAQ Accordion):** Smooth expand/collapse accordion with clear visual state indicators.
- **Fully Responsive & Accessible:** Fluid scaling across ultra-wide monitors, laptops, tablets, and mobile devices with `prefers-reduced-motion` support.

## ⚙️ How to Run Locally

You can run this site with any local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Or using Node.js / npx
npx serve .
```

Open `http://localhost:8000` in your browser.
